# 月圆之夜图鉴 · yyzy-codex

《月圆之夜》标准模式图鉴与对局攻略的静态站点，打开即用，无需安装。

- **图鉴**：https://newwbbie.github.io/yyzy-codex/
- **对局攻略**：https://newwbbie.github.io/yyzy-codex/guide.html

## 图鉴功能

- 按类别、种族、星级筛选，支持卡名、描述、特殊词条全文检索。
- 特殊词条筛选：只列出描述里实际出现该词条的卡牌。
- 点击卡牌查看详情；随从与舞伴可切换查看金色版本。
- 故事卡可查看同一张卡不同出现回合的效果，以及分支与关联卡。
- 全部为纯静态资源，搜索、筛选和详情切换都在浏览器本地完成。

## 对局攻略

- 从 9 个种族中选择本局实际出现的 4 个，中立卡自动可用。
- 实时统计本局卡池：每个星级的随从、装备、咒术数量。
- 按卡池质量、5–6 星终场身材、关键词机制浓度、资源倒转程度综合评分，
  在 4 个种族之间比较后再给出阵容推荐。
- 经济口径：买牌 3 金币、卖出 1 金币，刷新与经验按 1 金币折算；
  带 `*` 的倍率卡同名不叠加（普通 ×2、金色 ×3）。
